# NEON EMPIRE

Idle megacity tycoon. Tap the Core, buy ventures, hire managers, and ascend for Neon Cores.

## Play

Open `index.html` in a browser, or serve the folder:

```bash
python3 -m http.server 8080
```

Then visit `http://localhost:8080`.

## How to run a district

1. **Tap the Core** to mint cash (or press Space).
2. **Buy ventures** — Street Stall first, then the rest of the skyline.
3. **Run** a venture to start its cycle. When the bar fills, you get paid.
4. **Hire managers** so ventures run themselves while you are away.
5. **Install upgrades** for clicks, speed, and payouts.
6. **Overclock / Neon Surge** for short, brutal multipliers.
7. **Ascend** when you have pending Neon Cores. The city burns. The bonus stays.

Progress saves automatically in the browser.

## Tips

- Milestones at 10, 25, 50, 100… slash cycle time.
- Critical taps and combos juice the Core.
- Managers keep earning offline (up to 8 hours).
- Core Shop upgrades survive ascension.
